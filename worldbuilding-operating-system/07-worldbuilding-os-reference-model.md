# 07 — Worldbuilding Operating System: Reference Model

**Status:** PROPOSED / INSTRUCTIONAL ABSTRACTION — 2026-10-14  
**Role:** Define the conceptual machinery that earns the course the name “Operating System.”

## Model boundary

This is a **metaphorical and practical creator workflow**, not executable software. It abstracts transferable design principles from Reltroner Studio's Creative Compound Machine. It must **not** be mistaken for an Asthortera simulation engine, an LMS service definition or a generic law of fiction.

## Component architecture

| Component | Input | Operation | Output |
| --- | --- | --- | --- |
| Creative input | Observation, memory, curiosity, question | Choose an interesting seed | World premise candidate |
| Configuration / foundations | Premise and scope | Set world conditions, limits and exceptions | Bounded rule set |
| Entities / world state | Rules | Create places, agents, institutions, memories | Initial world model |
| Interactions | Entities and rules | Describe incentives, relationships and dependencies | Causal map |
| Simulation | Event, decision, initial state | Propagate effects and feedback | Changed world state |
| Expression | World model and reader question | Choose scene, backstory, reference or another format | Understandable artifact |
| Governance | Claims, changes and artifacts | Validate provenance, consistency and canon status | Revised world source of truth |
| Creative feedback | Changed state, unanswered consequence | Convert output into the next input | New question and next cycle |

## State-transition model

Let **S0** be the selected world's initial condition, **A** be an action or external event, and **R** the applicable world rules. A proposed world operation yields **S1 = transition(S0, A, R)**.

The learner's explanation must answer:
1. What was true before?
2. What happened and which actor or process caused it?
3. Which rule or constraint made the effect possible?
4. What actually changed?
5. Who experiences the benefit, cost or trade-off?
6. What future possibility now exists that did not exist before?

Not every fictional change needs a deterministic formula. This notation is a reasoning aid, not a promise of full physical computability.

## Creative compound loop

**Seed → structure → interaction → consequence → changed state → new pressure → new question → next possible action.**

A useful next idea **inherits something**: altered law, incentives, relationships, historical memory, access, geography, technology or local custom. Simple accumulation of unrelated lore is **not** compounding.

### Quality test

- What previous state generated this addition?
- What does it persistently change?
- Which dependency or tension follows?
- What earlier material acquires new significance?
- What new question can be generated without arbitrary invention?
- Can the same method work in another genre?

## Generative constraints

A binding world rule is not only a prohibition. By removing certain possibilities, it can surface fresh conflicts. Example: if memories may be transferred only with consent, the society gains a meaningful question about forged consent, inheritance and testimony.

Keep **global rules**, **local scoped rules**, and **exceptional cases** separate. Do not use a local anomaly to silently redefine the whole world.

## Multiple resolution levels

- **Micro:** agent experiences, choices, work, relationships.
- **Meso:** group, local institution, resource distribution, customs.
- **Macro:** larger society, world baseline and long-horizon effects.

An inference should not jump from one exceptional person's experience to claims about every inhabitant. Narrative attention is not a statistical population survey.

## Expression interface (optional patterns)

- **Current events:** What is happening now?
- **Backstory:** How did the present become possible?
- **Reference/wiki:** How does the world mechanism work?

These are transferable **presentation functions** inspired by the master source's Current Lore / Backstory / Wiki approach. Beginners may use any appropriate media, and no proprietary wiki interface is required.

## Canon and evidence boundary

The reference model describes how to make and test **learner-generated world claims**. It does not grant those claims authority inside Reltroner Studio's Asthortera canon. Draft facts can be changed; any public versioning requirement belongs to the specific creator's adopted publication policy.

## Human-language on-ramp

**First question:** “If your city changes a rule, what would one resident do differently tomorrow?” **Demonstrate:** a rule changes a choice; the choice changes the city; the changed city creates a new question. **Only then name** state transitions, institutional interdependencies and canon registers.

[Communication §11](https://github.com/Reltroner/reltroner-studio/blob/main/content/principles/reltroner-studio-communication-framework.md) uses six introductory stages: seed, constraint, interaction, consequence, changed state, new question. [Master §47](https://github.com/Reltroner/reltroner-studio/blob/main/content/principles/reltroner-studio-master-source-of-truth.md) adds system, new pressure, new possibility and further interaction. This is a **resolution difference**, not textually identical chains. L1–L3 is human relevance, L4 is the worked method, and L5 is the optional detailed model. A fictional example cannot by itself validate learner outcomes.

## Anti-patterns

Worldbuilding by infinite category checklist; arbitrary exceptions; one universal protagonist controlling all outcomes; teaching one ideology as required; conflating higher spectacle with higher causal quality; AI generating continuity claims without review; irreversible canon freeze before the learner understands their world.
