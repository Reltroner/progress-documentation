## Purpose

Archive the complete course concept, intended functions and use cases, learner outcomes, rationale, structure, assignments, capstone, reference model, and change controls in independent Markdown documents. This folder is a **curriculum proposal and portable handoff**, not a statement that LMS lessons, quizzes, deployment, mentorship, sales or learning outcomes exist.

The core promise to investigate: **help beginners develop a coherent fictional world and the independent ability to keep expanding it, rather than produce a large disconnected lore inventory**.

## Architecture at a glance

Imagine → Structure → Connect → Simulate → Evaluate → Express → Reuse.

Course-level sequence: **01 Fundamentals → 02 Seeds → 03 Foundations → 04 Lived World → 05 Systems → 06 Consequences → 07 Expression → 08 Canon & Workflows → Capstone**.

Current **candidate inventory**: 89 lessons, 8 assignments, 8 quizzes and 1 cumulative capstone. Lesson lengths, live course availability, study hours, language, quiz banks, grading thresholds and publication timeline are **not determined**.

## Non-negotiable interpretive separation

1. **Binding studio doctrine:** creative compounding, causal and canon integrity, learner independence, technology as an optional amplifier, epistemic honesty.
2. **Asthortera-specific canon:** its setting, baseline conditions, institutions, characters and narrative constraints. These are **not mandatory rules for a learner's fictional world**.
3. **This folder:** instructional design proposals, examples, assessment targets and implementation candidates. These require a **separate owner ratification** before becoming an accepted curriculum contract.
4. **Production status:** tracked by the relevant LMS engineering evidence, not by this documentation folder.

No writing here changes the Reltroner Studio apex source, frozen LMS technical contracts or unpublished Asthortera canon.
