## Question 1

**What is data?**

A. Information that a program can store and work with
B. A step-by-step solution to a problem
C. A programming language
D. A type of computer hardware

**Answer:** A

---

## Question 2

**What is a data structure?**

A. A programming language used to write code
B. A way to organize and store data
C. A step-by-step process for solving a problem
D. A result produced by a program

**Answer:** B

---

## Question 3

**What is an algorithm?**

A. A collection of stored values
B. A programming variable
C. A step-by-step process for solving a problem
D. A type of JavaScript data

**Answer:** C

---

## Question 4

**What is the main difference between a data structure and an algorithm?**

A. A data structure organizes data, while an algorithm describes how to process it
B. A data structure processes data, while an algorithm stores data
C. Both terms describe the same thing
D. Both terms only refer to JavaScript syntax

**Answer:** A

---

## Question 5

**Consider this problem:**

> Find the highest score from `[85, 70, 92, 78]`.

What are the correct input and output?

A. Input: `92` → Output: `[85, 70, 92, 78]`
B. Input: `[85, 70, 92, 78]` → Output: `92`
C. Input: `78` → Output: `85`
D. Input: `85` → Output: `70`

**Answer:** B

---

## Question 6

**In the pattern `Input → Process → Output`, what does the Process represent?**

A. The data received by the program
B. The result produced by the program
C. The operations performed on the input
D. The name of the programming language

**Answer:** C

---

## Question 7

**Why should a large programming problem be broken into smaller steps?**

A. To make the problem easier to understand and solve
B. To make the program use more code
C. To avoid testing the program
D. To remove the need for an algorithm

**Answer:** A

---

## Question 8

**When finding the highest score in `[85, 70, 92, 78]`, what is a reasonable first step?**

A. Remove the first score
B. Sort the scores immediately
C. Take `85` as the initial highest score
D. Return `78` as the highest score

**Answer:** C

---

## Question 9

**What is the main purpose of pseudocode?**

A. To execute a program directly
B. To describe solution logic before writing actual code
C. To permanently store program data
D. To replace programming languages

**Answer:** B

---

## Question 10

**Which sequence best represents a basic problem-solving process?**

A. Code → Test → Problem → Input → Output
B. Test → Code → Pseudocode → Problem → Result
C. Problem → Input/Output → Steps → Pseudocode → Code → Test
D. Code → Pseudocode → Problem → Test → Input

**Answer:** C

