## Evidence types

- **RATIFIED_STRATEGY**: owner-approved direction; not evidence an implementation exists.
- **FROZEN_TECHNICAL_CONTRACT**: normative technical boundary, modified only via explicit controlled change.
- **VERIFIED_SCOPED_EVIDENCE**: specific SHA, test, CI, receipt or observed output; says no more than its scope.
- **OWNER_REPORTED**: owner statement or screenshot; describe as reported/observed, not externally certified.
- **DESIGN_CANDIDATE**: proposed solution/architecture needing impact and conflict review.
- **MARKET_HYPOTHESIS**: outcome not validated by real buyer/learner evidence.
- **DEFERRED**: not part of currently approved delivery scope.
- **UNKNOWN / NEEDS_DISCOVERY**: missing or stale supporting data.

Never equate: idea = requirement; committed code = production deployment; CI PASS = security certified; exposure = engagement; engagement = comprehension; comprehension = adoption; adoption = payment; payment = retention; or Phase 2 readiness = monetization launch.

## Archive invariants

1. No pasted passwords, tokens, private keys, unredacted learner records or confidential operational secrets. This repository is public at archive creation.
2. A GitHub link points to authoritative living content; this archive does not freeze the linked branch forever. For deterministic reproduction, obtain explicit commit SHAs and acceptance receipts.
3. Cite exact document paths and bounded revision dates; avoid inventing current performance, revenue or production state.
4. Approved Phase 1/2 strategy does not authorize source edits, public DNS changes, production deployment, new paid software, or a new community marketing campaign.
5. Respect independent HRM and LMS architecture; shared VPS/Keycloak/technology does not merge business, DB, deployment, permissions or ownership.
6. Keep The Abyss of Comfort's unpublished seasons editable; internal labels such as “structured/established canon” are not proof of publicly immutable novel releases.
7. Revision of this archive requires a dated changelog/update and renewed source validation.
