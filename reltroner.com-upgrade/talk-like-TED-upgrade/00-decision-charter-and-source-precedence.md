## 1. Problem → solution → expected result

**Problem:** A sophisticated studio can be technically and conceptually well documented yet still impose excessive explanation cost on new visitors. Showing many impressive terms, subsystems or art pieces does not by itself establish felt relevance, a causally novel insight or a takeaway worth remembering.

**Owner-approved solution:** organize every first-contact journey around an **Emotional → Novel → Memorable** experience without sacrificing internal causal accuracy, meaningful reading depth, educational independence, status truth or reader autonomy. Translate the WOS candidate's usage-before-jargon learning model into creator-facing experiences, while retaining Asthortera's reader-first human dilemmas.

**Hypothesized result:** first-time visitors more easily understand whom Reltroner Studio serves, follow the relevant route, identify one traceable mechanism and remember a relevant insight. These are **design hypotheses until tested**, not measured outcomes.

## 3. Decision and authority semantics

1. **Binding studio constitution:** Studio Master Source of Truth v2.3 governs identity, two linked value engines, canon integrity, creator autonomy, evidence, funding discipline and §55 sequencing.
2. **Website ratified contract:** reltroner.com Phase 1 architecture contract, relevant later owner-approved ADRs and exact owner decisions govern website technical/security and UI invariants. Current accepted changes supersede *conflicting* historical routing and layout prescriptions only within their explicit scope.
3. **Communication framework:** Communication Framework v1.0 provides proposed, subordinate stakeholder translation, ethical outreach, anti-jargon and progressive disclosure patterns; it is not elevated into binding constitutional authority by this document.
4. **WOS candidate:** WOS v0.3 defines proposed learning design, not a live course, a validated learning outcome or a new website engineering mandate.
5. **Implementation truth:** repository HEAD, production deployments, code behavior, tests and contemporaneous visual QA establish what exists. A dated ledger is a snapshot, not a current-pass certificate.
6. **This folder:** owner-approved design direction and implementation specification. It cannot silently amend a security contract, prove release, make fiction canon or sell future offerings.

The user's explicit “I agree to all proposals” is recorded as **approval of this design concept**. A separately scoped engineering execution can use this as design input; it still must respect current release controls and effect-specific risk authorization.

## 4. Core invariants

- Preserve **one studio / two audience pathways**: creator and reader. Collaborator/portfolio entry remains secondary.
- Preserve creator ownership, tool independence and invitation without pressure. Do not require a specific AI, login, subscription or mentorship.
- Preserve dual-facing value: Creative Compound Machine offers a creator method; Asthortera / *The Abyss of Comfort* offer reader experiences and test the method longitudinally.
- Preserve published-canon vs hypothetical/non-canon concepts and distinguish fiction from Earth evidence. Do not change lore facts as part of a UX edit.
- Preserve current production security, privacy, provider, accessibility, media, navigation and cost protections, including the existing **Rp0 incremental spend** constraint unless the owner separately revises it.
- Preserve the six-stage learning exercise and existing functionality. Three cognitive anchors are **communication grouping**, not replacement of content hierarchy, interaction states, or learning requirements.
- Preserve the 8-module / 89-lesson WOS candidate without claiming all lessons available on the LMS.
- Respect scope of Phase 1/Phase 2 approvals. Approval of interface copy never announces that Phase 2 community branding or commercial mentorship is active.
